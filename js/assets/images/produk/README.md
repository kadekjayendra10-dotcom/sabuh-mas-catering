# Panduan Foto Produk — Sabuh Mas Catering

Folder ini disiapkan khusus untuk menyimpan foto produk asli Sabuh Mas Catering.

## Penamaan Berkas yang Direkomendasikan

Sesuai dengan 4 kategori layanan utama:
- `nasi-kotak.webp` (atau `nasi-kotak.jpg`) — Sajian paket nasi kotak personal
- `prasmanan.webp` (atau `prasmanan.jpg`) — Sajian meja prasmanan bersama
- `pmt-balita.webp` (atau `pmt-balita.jpg`) — Paket Pemberian Makanan Tambahan
- `snack-box.webp` (atau `snack-box.jpg`) — Sajian kue kudapan rapat

## Panduan Format & Dimensi
- **Format**: WebP (sangat disarankan untuk performa web) atau JPG berkualitas optimal.
- **Rasio**: 16:9 (atau 4:3), minimum dimensi 800 × 450 px agar tajam dan seragam di semua kartu.
- **Ukuran File**: Disarankan di bawah 250 KB per gambar agar waktu muat halaman tetap di bawah 3 detik.

## Cara Mengaktifkan di `index.html`
Setelah file foto asli dimasukkan ke folder ini:
1. Buka `index.html`.
2. Pada bagian `<section id="katalog">`, buka komentar `<!-- Slot Foto Produk ... -->` pada masing-masing kartu yang fotonya sudah siap.
3. Pastikan nilai `src` sesuai nama dan ekstensi berkas yang disimpan.
4. Simpan perubahan.
