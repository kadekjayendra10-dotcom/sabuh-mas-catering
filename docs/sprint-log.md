# Sprint log

## Sprint 0 — struktur demo

- Disiapkan halaman demo dengan komposisi editorial dan palet krem, cokelat, terracotta, serta hijau zaitun.
- Navigasi seluler dan ilustrasi sajian dibuat tanpa framework CSS.
- CSS dan JavaScript dipisah ke folder `css/` dan `js/`.
- Dokumentasi proyek, design brief, backlog, dan catatan ruang kerja ditambahkan.
- Informasi usaha yang belum terverifikasi tetap ditandai; belum ada foto produk asli.

## Sprint 1 — kelengkapan konten demo

- Katalog diperbarui dengan Nasi Kotak, Prasmanan, PMT Balita, dan Snack Box sesuai SKPL.
- Bagian Tentang memuat lokasi Gianyar, mulai berjalan sekitar 2018, dan catatan wawancara April 2019 tanpa nomor dokumen legal.
- Bagian pemesanan menunjukkan jalur WhatsApp untuk masyarakat umum dan e-Katalog/Inaproc untuk instansi pemerintah; tautan aktif menunggu konfirmasi.
- Kategori katalog memakai penanda tipografis dan bukan foto produk.
- Pemeriksaan visual desktop dilakukan di Chrome headless pada 1440 px; komposisi editorial dan palet lama tetap dipertahankan.
- Pemeriksaan layout seluler dilakukan pada viewport 390 px: lebar dokumen 390 px, konten utama berada di dalam viewport, dan tidak ada overflow horizontal.
- Semua tautan jangkar internal memiliki target yang cocok; empat kategori katalog terdeteksi.
- Menu hamburger diuji pada viewport 500 px: menu terbuka saat tombol ditekan dan tertutup setelah tautan navigasi dipilih.
- Pemeriksaan runtime JavaScript di Chrome headless pada breakpoint seluler tidak menangkap uncaught exception. Tautan kanal WhatsApp/Inaproc sengaja tidak aktif sebelum URL resmi dikonfirmasi.
